# Gear Second — Monkey D. Luffy Landing Page

An interactive, scroll-driven Gear Second experience built with React, Three.js, GSAP, and Framer Motion.

## Author

Created & Maintained by **Prathamwadiyar** ([prathamwadiyar@gmail.com](mailto:prathamwadiyar@gmail.com)).

## Tech Stack

- **React 19** + **Vite**
- **Three.js** / **@react-three/fiber** / **@react-three/drei**
- **GSAP** + **ScrollTrigger**
- **Framer Motion**

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run local development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```
